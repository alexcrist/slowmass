# Event fonts

Locally hosted, Latin-subset WOFF2 fonts from the Google Fonts CSS API. Fraunces was downloaded October 18, 2026; the four party fonts on October 19, 2026. Each family includes its SIL Open Font License. Content hashes in filenames allow immutable caching; use a new filename if bytes change. No runtime request contacts a font provider. Unsupported characters use the pairing’s system fallback.

Event pages, Create/Edit event, and signed-out event previews use the selected display face. Opening the Fonts dialog shows only each choice’s title in that face, loading the catalog on demand. There are no catalog preloads. Ordinary app pages and the Color theme dialog do not load the catalog. Fraunces uses weight 700; Bungee Shade, Monoton, Fascinate Inline, and Rubik Wet Paint use their native 400 weight. All body text uses the existing Source Sans 3 assets. Handwritten and the Fonts button reuse the existing Caveat font.

The catalog is 159,344 bytes in total. Rubik Wet Paint’s textured outlines account for 76,284 bytes; the complete catalog is smaller than the previous 205,160-byte catalog.
