# Google sign-in assets

The unmodified color Google G is from [Google's branding guidelines](https://developers.google.com/identity/branding-guidelines), downloaded from `https://developers.google.com/static/identity/images/g-logo.png`. Use it only for the labeled Google sign-in control, retaining its aspect ratio and colors.

Google Sans Medium is self-hosted, with Google's Fonts API subset for “Continue with Google”; the font is licensed under the accompanying OFL.txt. The subset only supports that label. These assets make no third-party request when the sign-in page loads.
