# Event calendar copies

Dependency-free formatting shared by the event dialog’s provider links and the authorized server calendar download. UTC instants preserve the host’s time across daylight saving and viewer time zones; Google also receives the event’s IANA zone. A missing end time uses a disclosed one-hour duration, independent of the twelve-hour RSVP closing rule. Copies include the title, time, location, description, and an ID-based slowmass link that requires existing event access. They never add the invitation credential, attendees, host emails, or media. Event edits and cancellations do not synchronize to calendar copies.

The iCalendar file has a stable event UID, private classification, RFC 5545 text escaping, CRLF line endings, and folding at 75 UTF-8 bytes without splitting characters. The server must authorize access before generating a file; these pure helpers grant no access. Provider links are inert until selected and need no OAuth connection or added dependency. Unit tests cover encoding, time boundaries, stable IDs, invitation exclusion, property injection, and Unicode folding.

References: [Google’s prefilled event links](https://developers.google.com/workspace/calendar/api/concepts/inviting-attendees-to-events#provide-a-link-for-users-to-add-the-event), [Apple’s calendar-file import](https://support.apple.com/guide/calendar/import-or-export-calendars-icl1023/mac), and [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545). Outlook uses its web compose deep link, a UI URL rather than a versioned API. Provider UI behavior and native-device importing remain manual verification items; generated links/files and slowmass access boundaries are tested locally.
