# Invite links

Each active member with a profile photo has one invite link, `/#invite/<token>`, to text to friends. `POST /api/invite-link` returns its URL and expiry. A link lasts seven days without extension. Once it expires or is revoked (by account deletion or restore quarantine), or its ciphertext can't be decrypted after an auth secret rotation, the next request installs a fresh credential and version ID in the member's single `invite_link` row; concurrent requests converge on whichever credential wins. Members cannot replace a current link early or name, count, or cap links. To stop a leaked link sooner, an operator revokes it (see the [operations runbook](../../../docs/operations.md#join-sources-and-shutting-down-bot-sign-ups)).

The token is 48 random characters. The row stores its SHA-256 hash for lookup and Better Auth authenticated encryption (with `AUTH_SECRET`) of the token so the owner can get the URL again. The token stays in URL fragments and request bodies, never in a server-visible URL. Signed out, `POST /api/invite-link/check` reveals only whether a link admits new people: no inviter name, avatar, expiry, or recipients. Forwarding a link lets anyone who receives it join until it expires. Signing in and joining through a link belong to [membership](../../membership/README.md), which records the link version on every join.

Scheduled cleanup removes up to 100 expired claims and clears the ciphertext of up to 100 expired, revoked, or inactive members' links per pass. Version IDs and hashes stay, so recorded joins remain traceable. Account deletion revokes the member's link immediately through their inactive membership and clears its ciphertext during account cleanup.

Integration tests in `tests/invite-links.test.ts` cover reuse without extension, renewal after expiry, revocation, and unreadable ciphertext, concurrent requests, owner/photo/session/origin requirements, signed-out checks, joining with recorded link versions, rechecks at verification without fallback, existing members, races, rollback, cleanup, deletion, and migration 0032.
