# Server

Hono runs on Cloudflare Workers. The composition root owns request IDs, privacy headers, mutation origin checks, route registration, and scheduled cleanup. Shared modules are [membership](membership/README.md), [email](email/README.md), [auth](auth/README.md), [photos](photos/README.md), and [request telemetry](telemetry/README.md).

[Account](features/account/README.md) depends on auth; account bootstrap also uses the people profile read. [People](features/people/README.md) owns profiles and relationships. [Avatars](features/avatars/README.md) uses people visibility and trusted photo processing. [Posts](features/posts/README.md) owns publication, feed, and cleanup. [Interactions](features/interactions/README.md) owns likes/comments; [notifications](features/notifications/README.md) derives current activity. [Push](features/push/README.md) depends on notifications for current visibility and manages optional session-bound subscriptions and delivery. [Invite links](features/invite-links/README.md) issues each member's renewable invite link; joining through it belongs to membership. [Events](features/events/README.md) owns event details, cover photos, links, guest lists, and messages; it uses membership for who may answer, which email verification shares, and account bootstrap reports whether a member has events. Relationship mutations, connection lists, posts, and interactions require a saved profile photo. Auth, own-profile setup, avatar upload, account deletion, events the member answered, Activity, push, discovery, and other members’ identity/avatar previews remain available without one. Profile previews withhold bios and accepted access until the viewer has a photo, including legacy automatic follows. Dependencies remain acyclic.

Unknown API routes return JSON errors. Private avatar and post delivery check authorization before R2 access; unknown media routes fail closed. `env.ts` is the binding contract. The default Wrangler environment is local; `production` explicitly selects the live resources and HTTPS origin.

Integration tests bundle the entry point into Miniflare and run real D1-backed sessions, profiles, relationships, and R2 authorization. Email is simulated or blocked at the outbound boundary. No browser or visual tests are run.

Feature `index.ts` files define public entry points; cross-feature consumers use those exports. Boundary tests resolve imports through the TypeScript configuration and check static imports, re-exports, dynamic imports, CommonJS imports, and type imports. Computed module loading is rejected. Dependency cycles and client/server crossings fail the check. On the server, the composition root may mount public router adapters, while routers and the root may not issue database queries.

[Startup diagnostics](diagnostics/README.md) retain bounded anonymous failure evidence in D1, independently of authentication. Telemetry supplies server snapshots; the composition root wires the write-only endpoint and retention cleanup.

[Device setup](features/device-setup/README.md) records whether a member may still see the optional install/notification suggestion in Activity. Account bootstrap composes its read with the people profile read and push's subscription check; neither install nor push consent gates member access. Push owns independent browser endpoints within authenticated sessions.

Events share curated appearance IDs with the client through the dependency-free [appearance contract](../shared/event-appearance/README.md); the event domain owns authorization and persistence.
