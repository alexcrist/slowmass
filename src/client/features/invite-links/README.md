# Invite links

`InviteLinkDialog` shows the member's current invite link with a Copy button, opened from the mail icon beside Settings on their own profile or the Invite to slowmass row in Settings. Both entry points require a profile photo. Opening it requests the link (`POST /api/invite-link`), which refreshes an active link to seven days from now while keeping its URL; expired or revoked links get a new version. It says “This link works for the next 7 days,” without a calendar date, and offers Try again if loading fails. The server owns expiry, renewal, and who may invite; see the [server feature](../../../server/features/invite-links/README.md). The signed-out side of an invite link lives in [Welcome](../welcome/README.md).
