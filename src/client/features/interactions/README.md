# Interaction controls

Post cards receive counts and like state with the post response. Like mutations are idempotent and return authoritative counts directly. The client applies that response without a second detail request; failed mutations retain the prior counts and allow retry. Comment changes still refresh post counts. Comments load only when expanded; the dedicated post page expands them initially. They use explicit paging and permission-controlled deletion. The delete control is a trash icon with an accessible Delete comment name and a 44px touch target. It opens a confirmation naming the author before sending the deletion. Cancellation makes no request, pending deletion disables dismissal and resubmission, and a failure retains the dialog for retry. Success closes it, removes the deleted row immediately, and refreshes comments and counts while keeping other avatars mounted; a failed count refresh reports that deletion succeeded instead of inviting another deletion. The shared feed/detail composer uses a pill outline and a circular green send button with a white icon and an accessible Post comment name. An aria-hidden text copy sizes the textarea from one to six lines as text wraps; longer drafts scroll internally, and clearing a sent draft shrinks it again. The composer starts at 44px tall, with a 22px text inset and 15px type matching post captions. The opaque send button stays flush with the bottom-right outer edges, covering the outline even while disabled, with a 44px target and an optically centered plane icon. Text-field focus darkens the single inset outline without adding an outer ring; the send button retains its keyboard focus indicator. The form has no outer margin; post-body padding matches the feed divider-to-next-header gap. Its label remains accessible to screen readers; whitespace-only and pending submissions are disabled. Failed submissions retain their text and UUID for unchanged retries; editing the text starts a new operation. Adding a comment revalidates the first page in place; posting from an older page requests the first page without rereading the old one. Comment rows retain stable identities when counts change. Refreshed post counts preserve expanded comments and unsent drafts. Comments and likes distinguish pending reads from empty lists, clear old read errors on retry, and ignore late responses from earlier pages. Network errors remain visible with retry controls; private content is not persisted in browser storage.

Heart and comment controls use icons with accessible names and positive counts. The heart toggles the like; the adjacent count opens a native Liked by modal with explicit pagination and username/avatar profile links. List separators appear only between people, with no divider below the last row. Icon-to-count spacing is the same for likes and comments. Comment authors use username profile links. Profile names are kept on profile pages.

The post heart aligns with the content's left edge. Its reaction group offsets the button's extra leading space while retaining the 44px button and the 4px gap to a positive count.

Comments have a compact avatar/text layout with the username inline before the body, relative time and a clickable positive like total beneath it, and a heart on the right. Threads remain flat. Comment likes use idempotent mutations returning authoritative counts; failure preserves the prior state. Their likers use the same modal as post likes. Closing or leaving cancels pending list reads, and reopening loads fresh authorized data.

The post interaction row has a 12px bottom gap. Comments use only 12px bottom padding, with no default list margins or top padding, giving matching gaps before the first comment, between comments, and before the composer. Metadata centers the timestamp, like total, and delete action with a shared 20px line height. The row and timestamp have no minimum height; button padding supplies 44px touch targets, and the delete control has its own styles rather than inheriting the generic icon button sizing. Equal 16px gaps separate the items; the 14px trash icon sits at the leading edge of its retained 44px target and is lifted 2px to align optically with Source Sans 3 text.
