# Welcome

Introduces Slowmass and requests a one-time email link when the backend is configured. Missing credentials disable sign-in with an honest availability message; network and link errors are distinct. The generic sent state does not reveal whether an address has an invitation.

A signed-in member can create email-bound invitations and sign out. Invitation creation explicitly explains that no invitation email is sent: the member shares the app URL with their friend. The account confirmation is an interim screen until profile onboarding and photo sharing are implemented.
